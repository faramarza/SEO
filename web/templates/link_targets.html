🎯 Link Targets

Your outreach worksheet: one row per page + keyword, ranked, with a number on every row — how many more referring domains that page needs to match the sites on page 1 for that term. This is what you build outreach from: the pages, the terms, and the link count for each. Nothing is filtered and no verdict hides a number — a 0 means you already out-link the competition (so links won't be the lever there), a 🎯 +N is a reachable win, and a big +N is a gap you can see and judge yourself. Measured via DataForSEO; paste an Ahrefs SERP export on any row to cross-check with a second index (they count referring domains differently, so numbers will differ — that's normal).

DataForSEO runs on the Serper SERP + backlink totals (cached, daily-capped — a full pass spreads over a few days). For an Ahrefs number on a row: click Open in Ahrefs, go to Keywords Explorer → SERP overview → Export, then Upload Ahrefs CSV on that row and choose the file.
